# FocusDog Growth System

Version: 1.0

## Core Loop

专注 -> EXP

EXP -> 升级

升级 -> 狗窝升级

金币 -> 购买家具

连续专注 -> 解锁皮肤

## MVP Growth Rules

- 完成一次专注后获得 EXP
- EXP 满 100 后提升 1 级
- 连续专注天数显示在 Growth 和 Profile 页面
- 完成专注时触发 Dog Jump、Confetti 和 EXP Increase 动画
